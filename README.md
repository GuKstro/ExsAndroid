
Esse repositório contém uma coleção de projetos Android desenvolvidos como exercícios para aprender e praticar conceitos de desenvolvimento mobile.

## 1. Sistema de Compras com CheckBox
- **Descrição:** O usuário seleciona produtos de mercado (arroz, leite, carne, etc.) usando CheckBoxes. Ao clicar em "Calcular Total", o app mostra o valor total da compra.
- **Tecnologias Utilizadas:** CheckBox, Button, TextView.

## 2. Reajuste Salarial com RadioButton
- **Descrição:** O usuário digita seu salário e escolhe o percentual de reajuste (40%, 45% ou 50%). O novo salário é calculado e exibido.
- **Tecnologias Utilizadas:** EditText, RadioGroup, RadioButton, Button, TextView.

## 3. Cadastro de Clientes - Tem de Tudo
- **Descrição:** App com 3 Activities:
  - Tela de boas-vindas com logotipo.
  - Formulário com TextInputLayout para o nome.
  - Tela de confirmação com mensagem dinâmica e botão para voltar.
- **Tecnologias Utilizadas:** Intent, TextInputLayout, TextView, Button.

## 4. Lanche Fácil - Registro de Pedidos
- **Descrição:** App com 3 telas:
  - Tela inicial com logomarca.
  - Formulário com nome e seleção de lanche.
  - Tela de resumo com dados do pedido e botão de retorno.
- **Tecnologias Utilizadas:** TextInputLayout, Button, TextView, Intent, ImageView.

## 5. Simulador de Pedidos em Pizzaria
- **Descrição:** App dividido em 3 atividades:
  - Seleção de sabores via CheckBox.
  - Escolha do tamanho e pagamento com RadioGroup.
  - Tela de resumo com detalhes e valor total.
  - O valor é calculado com base na combinação de sabores e tamanho.
- **Tecnologias Utilizadas:** CheckBox, RadioButton, Intent, TextView, Button.

## Tecnologias Gerais Utilizadas
- **Linguagem de Programação:** Java
- **Ambiente de Desenvolvimento:** Android Studio
- **Interface de Usuário:** XML para Layout
- **Componentes de Material Design:** TextInputLayout
